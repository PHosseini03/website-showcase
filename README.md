# Website-Portfolio – Live-Showcase

Eine Übersichtsseite für 10 Demo-Websites. Ein Klick auf eine Website lädt sie **live** in einem Geräte-Rahmen (Desktop, Tablet oder Smartphone) – man sieht sie laden und kann sich durch alle Seiten klicken.

| Website | Branche |
|---|---|
| `solar-power` | Solarenergie |
| `pharmacy` | Apotheke |
| `clinic-doctors` | Praxis & Ärzte |
| `restaurant` | Restaurant |
| `home-services` | Sanitär, Reinigung & Reparaturen |
| `real-estate` | Immobilien |
| `beauty-spa` | Beauty-Salon & Spa |
| `law-firm` | Rechtsanwaltskanzlei |
| `gaming-shop` | Online-Shop für Gaming & PC-Hardware |
| `hotel` | Hotel & Resort |

Jede Website liegt in einem eigenen Repository (React + TypeScript, Python FastAPI) und wird per GitHub Actions auf GitHub Pages veröffentlicht. In der Live-Demo läuft kein Backend: Inhalte kommen aus den mitgelieferten Demo-Daten, Formulare zeigen eine Bestätigung, senden aber nichts.

Direktlinks: `…/website-showcase/#restaurant` öffnet eine Website direkt im Viewer.

*Alle Unternehmen, Personen und Zahlen sind fiktiv. Fotos über Unsplash.*
